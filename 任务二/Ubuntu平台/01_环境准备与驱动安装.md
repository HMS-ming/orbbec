# 环境准备与驱动安装（Ubuntu）

> 位置：任务二 / Ubuntu平台
>
> 前置：主机已安装 Ubuntu，并具备可用的软件源（可访问 ROS 2 与系统软件包）
>
> 相关：[通用 01 接入方案与准备](../通用/01_接入方案与准备.md) · [Ubuntu平台 / 02 启动与查看数据流](02_启动与查看数据流.md)
>
> 本步目标：安装 ROS 2 驱动包，确认相机被节点正确识别
>
> 示例环境：示例设备 **Astra 2**，驱动 **OrbbecSDK ROS2 Wrapper v2.10.6**，**ROS 2 Jazzy**；下文的 `<ROS 发行版>` 即该版本的发行版代号

## 0. 结论

✅ 驱动以预编译 deb 形式发布：按「ROS 2 发行版 + 主机架构」取一个压缩包，解压后安装其中的两个 deb，**不需要编译**。

✅ 安装包自带 udev 规则与 SDK 运行库，节点以普通用户运行即可，**不需要 `sudo`**。

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Ubuntu；x64 平台已验证 Ubuntu 22.04 |
| ROS 2 | Humble / Jazzy / Lyrical（发行包覆盖这三种） |
| 主机架构 | `amd64` 或 `arm64` |
| 磁盘空间 | 驱动与依赖合计数百 MB |

⚠️ **ARM64 的支持范围**：受支持的 ARM64 平台为 NVIDIA Jetson 系列。其他 ARM64 平台在架构上可以安装 `arm64` 包，但不在受支持平台列表内，兼容性需自行验证。

## 2. 安装 ROS 2

机器上已有可用的 ROS 2 时，跳过本节。未安装时按 [ROS 2 Ubuntu 安装说明](https://docs.ros.org/en/rolling/Installation/Ubuntu-Install-Debs.html) 安装桌面版（含 RViz2，用于后续查看图像与点云）：

```bash
sudo apt install ros-<ROS 发行版>-desktop
```

安装完成后，每个终端使用前都需要 source 环境：

```bash
source /opt/ros/<ROS 发行版>/setup.bash
```

建议把该命令写入 `~/.bashrc`，避免每次手动执行。

## 3. 下载驱动

驱动发布页：[OrbbecSDK_ROS2 Releases](https://github.com/orbbec/OrbbecSDK_ROS2/releases)。国内网络可改用 [Gitee 镜像](https://gitee.com/orbbecdeveloper/OrbbecSDK_ROS2)。

发布页的 Windows 无关，Linux 包统一命名为 `orbbec-ros2-debs-<发行版>-<架构>.zip`，一个压缩包对应一种发行版与一种架构的组合：

| 文件 | 适用环境 |
|---|---|
| `orbbec-ros2-debs-humble-amd64.zip` | Humble · x64 |
| `orbbec-ros2-debs-humble-arm64.zip` | Humble · ARM64 |
| `orbbec-ros2-debs-jazzy-amd64.zip` | Jazzy · x64 |
| `orbbec-ros2-debs-jazzy-arm64.zip` | Jazzy · ARM64 |
| `orbbec-ros2-debs-lyrical-amd64.zip` | Lyrical · x64 |
| `orbbec-ros2-debs-lyrical-arm64.zip` | Lyrical · ARM64 |

✅ 按上表的两个字段（发行版、架构）即可唯一确定应下载的文件。发行版用 `printenv ROS_DISTRO` 确认，架构用 `uname -m` 确认（`x86_64` 对应 `amd64`，`aarch64` 对应 `arm64`）。

若所用 ROS 2 发行版的软件源中已收录该驱动（`apt list | grep orbbec` 可确认），也可直接用系统包管理器安装。发行包版本通常落后于 Releases 的最新版，需要最新功能时仍以 Releases 为准。

下载后解压：

```bash
unzip orbbec-ros2-debs-<发行版>-<架构>.zip -d orbbec_ros2
ls orbbec_ros2
```

解压结果包含两个文件：

```text
ros-<发行版>-orbbec-camera-msgs_<版本>_<架构>.deb
ros-<发行版>-orbbec-camera_<版本>_<架构>.deb
```

## 4. 安装依赖与驱动

先装驱动所需的系统与 ROS 依赖：

```bash
sudo apt install -y libgflags-dev libgoogle-glog-dev nlohmann-json3-dev \
  ros-<ROS 发行版>-image-transport ros-<ROS 发行版>-image-transport-plugins \
  ros-<ROS 发行版>-compressed-image-transport ros-<ROS 发行版>-image-publisher \
  ros-<ROS 发行版>-camera-info-manager ros-<ROS 发行版>-diagnostic-updater \
  ros-<ROS 发行版>-diagnostic-msgs ros-<ROS 发行版>-statistics-msgs \
  ros-<ROS 发行版>-backward-ros ros-<ROS 发行版>-xacro
sudo apt install -y libdw-dev libssl-dev python3-tabulate
```

再安装两个 deb：

```bash
cd orbbec_ros2
sudo dpkg -i ros-<发行版>-orbbec-camera-msgs_<版本>_<架构>.deb \
             ros-<发行版>-orbbec-camera_<版本>_<架构>.deb
```

⚠️ 若 `dpkg` 提示依赖未满足，执行 `sudo apt-get install -f` 补齐依赖后再确认包状态：

```bash
dpkg -l | grep orbbec
```

两行状态应为 `ii`。

需要在机器人 URDF 中引用相机模型时，再安装机型描述包：

```bash
sudo apt install -y ros-<ROS 发行版>-orbbec-description
```

该包提供 `share/orbbec_description/urdf/` 下各型号的 xacro 模型与网格文件，用法见 [通用 03 第 1 节](../通用/03_机器人集成要点.md)。

安装后的文件位置（以 ROS 2 安装根目录 `/opt/ros/<ROS 发行版>/` 为基准）：

| 路径 | 内容 |
|---|---|
| `share/orbbec_camera/launch/` | 各型号的启动文件 |
| `share/orbbec_camera/config/` | 参数配置文件 |
| `share/orbbec_camera/udev/` | udev 规则源文件 |
| `share/orbbec_camera/examples/` | 示例代码 |
| `lib/orbbec_camera/` | 节点与工具的可执行文件（`orbbec_camera_node`、`list_devices_node` 等） |
| `lib/liborbbec_camera.so` | 相机节点插件 |
| `lib/libOrbbecSDK.so.<版本>` | 驱动自带的 SDK 运行库 |
| `lib/extensions/` | 深度引擎与后处理扩展库 |

查询本机实际安装的全部文件：

```bash
dpkg -L ros-<ROS 发行版>-orbbec-camera | less
```

⚠️ 上述路径属于 ROS 2 的安装根目录，与任务一安装的独立 SDK（`/opt/OrbbecSDK_<版本>/`）是两套独立的目录结构，两者互不替代。

## 5. 设备权限（udev 规则）

Linux 下访问 USB 设备需要权限规则，否则打开设备会失败、只能用 `sudo` 运行节点。安装包会把规则文件安装到系统目录：

```text
/etc/udev/rules.d/99-obsensor-libusb.rules
```

规则对**已连接**的设备需要重新触发才能生效，重新插拔相机也可以：

```bash
sudo udevadm control --reload-rules && sudo udevadm trigger
```

确认规则文件存在：

```bash
ls /etc/udev/rules.d/ | grep obsensor
```

## 6. 验证设备识别

```bash
source /opt/ros/<ROS 发行版>/setup.bash
ros2 run orbbec_camera list_devices_node
```

正常输出示例：

```text
[INFO] [...] [list_device_node]: name: Orbbec Astra2
[INFO] [...] [list_device_node]: pid: 0x0660
[INFO] [...] [list_device_node]: serial: <序列号>
[INFO] [...] [list_device_node]: connection: USB3.0
[INFO] [...] [list_device_node]: firmware version: <固件版本>
[INFO] [...] [list_device_node]: usb port: <端口号>
```

`connection` 应为 `USB3.0`。若显示 `USB2.0`，深度图的分辨率与帧率将受限，应改用 USB 3.0 端口与线材。

⚠️ 列表为空时，依次检查：相机是否插在 USB 3.0 端口、`lsusb` 是否能看到设备、udev 规则是否生效（见第 5 节）。`lsusb` 看不到设备属于硬件连接问题，与驱动无关。

## 7. 从源码构建（发行版不在发行包覆盖范围时）

发行包只覆盖 Humble / Jazzy / Lyrical。使用 Foxy、Rolling 或需要修改驱动代码时，从源码构建：

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src
git clone https://github.com/orbbec/OrbbecSDK_ROS2.git
cd OrbbecSDK_ROS2 && git checkout v2-main
cd ~/ros2_ws
colcon build --event-handlers console_direct+ --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

源码构建方式下，udev 规则需手动安装：

```bash
sudo bash ~/ros2_ws/src/OrbbecSDK_ROS2/orbbec_camera/scripts/install_udev_rules.sh
```

⚠️ 源码构建使用 `v2-main` 分支；`main` 分支对应 SDK v1 世代，仅用于 v2 已不支持的旧型号。
