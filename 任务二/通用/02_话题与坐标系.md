## 0. 结论

✅ 相机节点默认以 `/camera` 为命名空间发布深度、彩色、红外三路图像，外加点云、IMU、内参与状态话题；所有图像话题仅在对应流使能时发布。

✅ 深度图编码为 `16UC1`，**单位毫米**，像素值 `0` 表示无效（超量程或无回波），不需要再乘比例系数。

## 1. 话题清单

默认启动（深度、彩色、红外三路流全开）时的话题：

| 话题 | 类型 | 内容 |
|---|---|---|
| `/camera/depth/image_raw` | `sensor_msgs/msg/Image` | 深度图，`16UC1`，毫米 |
| `/camera/depth/camera_info` | `sensor_msgs/msg/CameraInfo` | 深度相机内参与畸变模型 |
| `/camera/depth/points` | `sensor_msgs/msg/PointCloud2` | 由深度图生成的点云（需 `enable_point_cloud`） |
| `/camera/color/image_raw` | `sensor_msgs/msg/Image` | 彩色图，`rgb8` |
| `/camera/color/image_raw/compressed` | `sensor_msgs/msg/CompressedImage` | 彩色压缩流（随发布插件使能出现） |
| `/camera/color/camera_info` | `sensor_msgs/msg/CameraInfo` | 彩色相机内参 |
| `/camera/ir/image_raw` | `sensor_msgs/msg/Image` | 红外图，`mono8` |
| `/camera/ir/camera_info` | `sensor_msgs/msg/CameraInfo` | 红外相机内参 |
| `/camera/gyro_accel/sample` | `sensor_msgs/msg/Imu` | 陀螺仪与加速度计融合输出 |
| `/camera/accel/imu_info` | `orbbec_camera_msgs/msg/IMUInfo` | 加速度计标定参数 |
| `/camera/gyro/imu_info` | `orbbec_camera_msgs/msg/IMUInfo` | 陀螺仪标定参数 |
| `/camera/device_status` | `orbbec_camera_msgs/msg/DeviceStatus` | 设备在线状态与各流实际发布帧率 |
| `/camera/depth_filters/status` | `orbbec_camera_msgs/msg/DepthFiltersStatus` | 深度后处理滤波器状态 |
| `/tf` `/tf_static` | `tf2_msgs/msg/TFMessage` | 相机内部坐标系变换 |

⚠️ 未使能的流不会发布对应话题。例如关闭红外流后，`/camera/ir/image_raw` 不再出现，依赖它的订阅端会一直等不到数据。

⚠️ **IMU 默认关闭**：表中三条 IMU 相关话题（`gyro_accel/sample`、`accel/imu_info`、`gyro/imu_info`）在启动参数 `enable_accel` 与 `enable_gyro` 均默认为 `false`，**默认启动时不会发布**。需要 IMU 数据时在启动命令追加：

```bash
ros2 launch orbbec_camera astra2.launch.py enable_accel:=true enable_gyro:=true
```

## 2. 图像编码与取值

| 流 | 编码 | 典型分辨率 | 取值含义 |
|---|---|---|---|
| 深度 | `16UC1` | 800 × 600 | 每像素 16 位无符号整数，单位毫米；`0` 为无效值 |
| 彩色 | `rgb8` | 1280 × 720 | 三通道 8 位；设备侧为 MJPG 时由驱动解码后发布 |
| 红外 | `mono8` | 800 × 600 | 单通道 8 位灰度 |

深度值的读取方式（C++）：

```cpp
auto depth = msg->data;                       // sensor_msgs::msg::Image::_data_type
uint16_t d = depth[row * width + col];        // 单位：毫米，0 表示无效
```

Python 侧建议用 `numpy.frombuffer` 转为 `uint16` 数组后按二维索引访问，避免逐像素处理带来的开销。

⚠️ 彩色图默认以 MJPG 采集、在主机侧解码为 `rgb8` 后发布。带宽允许时也可将 `color_format` 设为 `YUYV` 或 `RGB`，省去解码开销，但占用更高。

## 3. 相机内参

`camera_info` 提供该流的内参与畸变模型，用于像素坐标与相机三维坐标互算：

| 字段 | 含义 |
|---|---|
| `k` | 3 × 3 内参矩阵，包含焦距 `fx` `fy` 与主点 `cx` `cy` |
| `d` | 畸变系数；模型由 `distortion_model` 给出 |
| `distortion_model` | 示例设备的深度流为 `rational_polynomial` |
| `frame_id` | 与该流图像一致的坐标系名，如 `camera_depth_optical_frame` |

反投影公式（深度图，单位毫米→米）：

```text
Z = 深度像素值 / 1000
X = (u - cx) * Z / fx
Y = (v - cy) * Z / fy
```

## 4. 坐标系与 TF

节点默认发布相机内部各传感器之间的静态变换（`publish_tf` 默认开启）。坐标系分两类：

| 类型 | 示例 | 轴向约定 |
|---|---|---|
| 机体坐标系 | `camera_depth_frame`、`camera_color_frame` | ROS 约定：X 向前、Y 向左、Z 向上 |
| 光学坐标系 | `camera_depth_optical_frame`、`camera_color_optical_frame` | 相机约定：Z 向前（光轴）、X 向右、Y 向下 |

图像与点云消息的 `frame_id` 均为**光学坐标系**。相机节点默认发布的坐标系包括：

```text
camera_depth_frame ─┬─ camera_depth_optical_frame
                    ├─ camera_ir_frame ── camera_ir_optical_frame
                    ├─ camera_color_frame ── camera_color_optical_frame
                    ├─ camera_accel_frame ── camera_accel_optical_frame
                    └─ camera_gyro_frame ── camera_gyro_optical_frame
```

⚠️ 这些是**相机内部**的坐标系，根节点 `camera_depth_frame` 与机器人机体之间没有变换。接入机器人时必须补一条机体到相机的静态变换，否则 RViz2 中会报 `No transform from [camera_depth_optical_frame] to [base_link]`。做法见 [通用 03 机器人集成要点](03_机器人集成要点.md)。

## 5. QoS

图像话题的默认 QoS 为 `RELIABLE / VOLATILE / KEEP_LAST(10)`。订阅端使用 ROS 2 默认 QoS 即可匹配；若订阅端显式改为 `BEST_EFFORT`，与 `RELIABLE` 发布端仍可通信，但反向不成立。

## 6. 服务接口

除话题外，节点还提供服务用于查询与控制。常用服务：

| 服务 | 作用 |
|---|---|
| `/camera/get_device_info` | 查询型号、序列号、固件版本、SDK 版本 |
| `/camera/get_sdk_version` | 查询当前 SDK 版本 |
| `/camera/get_streams_enable` | 查询各流使能状态 |
| `/camera/set_color_exposure` / `/camera/set_color_gain` | 设置彩色曝光与增益 |
| `/camera/set_depth_exposure` / `/camera/set_depth_gain` | 设置深度曝光与增益 |
| `/camera/set_color_flip` / `/camera/set_depth_flip` | 翻转图像 |
| `/camera/set_color_rotation` / `/camera/set_depth_rotation` | 旋转图像 |
| `/camera/save_images` | 保存当前帧到磁盘 |
| `/camera/save_point_cloud` | 保存当前点云 |
| `/camera/set_bag_recording` | 开始或停止设备级录制 |
| `/camera/send_software_trigger` | 软触发一次采集 |
| `/camera/reboot_device` | 重启设备 |

查询设备信息：

```bash
ros2 service call /camera/get_device_info orbbec_camera_msgs/srv/GetDeviceInfo '{}'
```

完整服务列表用 `ros2 service list | grep -v parameters` 查看。

## 7. 常用调试命令

| 目的 | 命令 |
|---|---|
| 列出话题 | `ros2 topic list` |
| 查看某路实际帧率 | `ros2 topic hz /camera/depth/image_raw` |
| 查看消息结构 | `ros2 topic echo /camera/depth/camera_info --once` |
| 查看带宽 | `ros2 topic bw /camera/depth/image_raw` |
| 查看各流帧率与延迟 | `ros2 topic echo /camera/device_status --once` |
| 录制数据 | `ros2 bag record -o <目录> /camera/depth/image_raw /camera/color/image_raw` |
| 查看节点与参数 | `ros2 node list` · `ros2 param list /camera/camera` |

⚠️ `ros2 topic hz` 与 `ros2 topic echo` 依赖订阅端，第一次统计需要等待数帧。同时运行多个订阅端会增加主机负载，排查结束后应及时关闭。
