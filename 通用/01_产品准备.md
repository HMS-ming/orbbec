# 01 产品准备

> **位置**：奥比中光深度相机通用上手 WIKI · 通用篇（Windows / Ubuntu 共用）
>
> **前置**：无（最先读本篇）
>
> **相关**：[Windows · 01 下载安装与准备](../Windows平台/01_下载安装与准备.md) · [Windows · 02 SDK 示例上手](../Windows平台/02_SDK示例上手.md) · [Ubuntu · 01 下载安装与准备](../Ubuntu平台/01_下载安装与准备.md)
>
> **本步目标**：相机点亮、接线规范、主机识别到设备，并确认该用 SDK v1 还是 v2。

## 1. 开箱核对

| 物品       | 数量  | 核对要点                                                  |
| -------- | --- | ----------------------------------------------------- |
| 相机本体     | ×1  | 记下**机身丝印上的型号**（如 `Astra 2`，型号号 `A30003-15`）—— 第 6 节要用 |
| 数据 + 供电线 | ×1  | 多为 Type-C 一线通；个别机型 Type-A→Type-C，网口机型用网线（以实物与规格书为准）   |
| 出厂资料     | ×1  | 快速入门 / 保修卡（视渠道而定）                                     |
| 选配件      | 视订单 | 支架、同步线、Sync Hub 等                                     |

- 品相：镜头前盖玻璃无划痕 / 指纹，接口无变形，线缆无折痕。
- 多数 USB 机型**无需外接电源**，数据与供电共用同一根 USB 3.0 线；功耗以规格书为准。

## 2. 接口与指示灯

**接口**

| 类型                  | 出现场合        | 用途                    |
| ------------------- | ----------- | --------------------- |
| USB Type-C / Type-A | 绝大多数 USB 机型 | 数据 + 供电               |
| 8-Pin / 同步口         | 支持多机同步的机型   | 多相机同步触发               |
| 网口（以太网 / GMSL）      | 网络型机型       | 数据（部分支持 PoE），非 USB 直连 |

**指示灯**

| 状态        | 含义             |
| --------- | -------------- |
| 常亮        | 已上电且工作正常       |
| 呼吸 / 规律闪烁 | 初始化中，或已就绪      |
| 熄灭        | 低功耗待机          |
| 无规律闪烁     | 故障 → 拔掉所有线重插复位 |

**安装孔**：通常 1/4-20 UNC（三脚架螺纹）+ M3 螺孔。

## 3. 主机要求

| 平台          | 系统                                                       | 硬件                                  |
| ----------- | -------------------------------------------------------- | ----------------------------------- |
| Windows     | Windows 10 及以上（x64）                                      | USB 3.0 口 / 千兆网口、四核 2.9GHz+、8GB+ 内存 |
| Ubuntu      | 20.04 / 22.04+（官方已验证 20.04 / 22.04 / 24.04）              | 同上                                  |
| Linux ARM64 | Ubuntu（Jetson AGX Orin / Orin NX / Orin Nano / Xavier 等） | 同上，走 arm64 包                        |

> 以上为 **Orbbec SDK v2** 的通用要求。若需自行**编译示例**，另加 GCC ≥ 7.5、CMake ≥ 3.15、OpenCV（推荐 3.4.0）。

## 4. 连接要点

1. **用 USB 3.0 口**（通常蓝色 / 带 SS 标识）；插 USB 2.0 会降速，可能跑不到高分辨率高帧率。
2. **直连主机**，不经无源 USB Hub / 扩展坞 —— 供电不足会表现为「设备时有时无 / 数据流中断」。
3. **用随机附带的线**；需延长时选 USB 认证、同时支持数据 + 供电的线，长度 **1–1.5m** 为宜。劣质长线是「找不到设备」的头号原因。
4. 识别不到 / 不响应时：**拔掉所有线，重新插回主机**复位。
5. 机器人场景走线：USB / 网线避开电机驱动与大电流线束。

## 5. 确认主机已识别

| 平台      | 怎么确认                                                          | 详细步骤                                               |
| ------- | ------------------------------------------------------------- | -------------------------------------------------- |
| Windows | 设备管理器（`Win + R` → `devmgmt.msc`）「摄像头」下可见；或 OrbbecViewer 能列出设备 | [Windows · 01 下载安装与准备](../Windows平台/01_下载安装与准备.md) |
| Ubuntu  | `lsusb` 能看到奥比设备                                               | [Ubuntu · 01 下载安装与准备](../Ubuntu平台/01_下载安装与准备.md)           |

```bash
lsusb            # 列出所有 USB 设备
lsusb -d 2bc5:   # 只看奥比设备（VID = 2bc5）
```

> 示例（Astra 2）：`ID 2bc5:0660`。
>
> 排查顺序：换 USB 口 → 换线 → 去掉 Hub 直连 → 拔插复位 → 再查驱动 / 权限。

## 6. 确认该用 SDK v1 还是 v2

不同型号支持的 SDK 世代不同，**这决定应下载哪一套包**。

1. **查支持矩阵**：在 [Orbbec SDK v2 README](https://github.com/orbbec/OrbbecSDK_v2) 的「型号 × v1 / v2 支持状态」表里找第 1 节记下的型号，看 **Orbbec SDK v2** 那一列。
2. **按判定决定**：

| 判定                                                 | 动作                                                                                              |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `recommended for new designs` / `full maintenance` | ✅ 用 v2 —— 本 WIKI 全套适用                                                                           |
| `limited maintenance` / `not supported`            | ⚠️ 改用 v1：[Orbbec SDK v1 仓库](https://github.com/orbbec/OrbbecSDK)（其 Releases 里也有配套 OrbbecViewer） |
| 表里查不到                                              | 到 [官方文档中心](https://doc.orbbec.com/) 按型号查，或联系官方 FAE                                              |

1. **双协议型号按固件判断**：`Astra Mini Pro` / `Astra Mini S Pro` 同一型号存在两种协议固件 —— 固件 `v2.x.x`（UVC）用 v2，`v1.x.x`（OpenNI）只能用 v1。固件号在 OrbbecViewer 或设备信息里查。

> ⚠️ 已知 **v2 不支持**的型号：`Astra+`、`Astra Pro Plus`、`Gemini 2 XL`。
>
> **示例（Astra 2）**：v1 列 `full maintenance`、v2 列 `recommended for new designs` → **用 v2**；官方支持表中最小固件 = 推荐固件 = **2.8.20**。

## 7. 安全与保养

1. **请勿触摸镜头** —— 指纹会影响成像质量。
2. 请勿跌落或施加外力；**拆解机壳 / 支架会失去保修**。
3. 请勿私自改装，可能导致永久损坏或精度异常。
4. 长时间连续使用时机身温度升高属正常现象；必要时增加散热空间。
5. 产品使用激光（通常为 **Class 1**）：不建议长时间直视；红外光肉眼不可见，尤须避免近距离正对。

| --------- | -------------------------------------- |
| 型号        | A30003-15                              |
| VID / PID | `2bc5:0660`                            |
| 原理        | 结构光，红外 850nm                           |
| 量程        | 0.6 – 8m（推荐 0.6 – 5m）                  |
