# 奥比中光深度相机通用上手 WIKI

深度相机上手教程：开箱 → 安装 → 跑通示例 → 自写取流 → 接入机器人。不针对特定机型，示例以 **Astra 2** 为准（**Orbbec SDK v2.10.6**）。

## 文档结构

```text
任务一\                任务①「获取和查看数据流」全部成稿
├── 通用\               平台无关，共性问题只讲一遍
│   ├── 01 产品准备
│   └── 03 自写取流
├── Windows平台\         一体安装包 + 元数据注册
│   ├── 01 下载安装与准备
│   └── 02 SDK 示例上手
└── Ubuntu平台\          deb 一体包 + udev 规则
    ├── 01 下载安装与准备
    └── 02 SDK 示例上手

任务二\                任务②「在机器人中接入深度相机（ROS 2）」全部成稿
├── 通用\               平台无关，共性问题只讲一遍
│   ├── 01 接入方案与准备
│   ├── 02 话题与坐标系
│   └── 03 机器人集成要点
└── Ubuntu平台\          ROS 2 驱动安装 + 启动与查看
    ├── 01 环境准备与驱动安装
    └── 02 启动与查看数据流
```

## 阅读顺序

### 任务一：获取和查看数据流

1. [通用 / 01 产品准备](任务一/通用/01_产品准备.md) —— 开箱核对、连接与识别；确认该用 SDK v1 还是 v2（由相机型号与固件决定，与主机无关）
2. [Windows / 01](任务一/Windows平台/01_下载安装与准备.md) 或 [Ubuntu / 01](任务一/Ubuntu平台/01_下载安装与准备.md) —— 安装并完成设备权限配置；之后即可用 OrbbecViewer 查看图像
3. [Windows / 02](任务一/Windows平台/02_SDK示例上手.md) 或 [Ubuntu / 02](任务一/Ubuntu平台/02_SDK示例上手.md) —— 编译并运行 SDK 示例，跑通视频流
4. [通用 / 03 自写取流](任务一/通用/03_SDK自写取流.md) —— 写自己的取流程序（同一份代码，两平台编译命令都在文内）

### 任务二：在机器人中接入（ROS 2）

1. [通用 / 01 接入方案与准备](任务二/通用/01_接入方案与准备.md) —— 接入方式、驱动版本与发行版对应、型号对应的启动文件
2. [Ubuntu / 01 环境准备与驱动安装](任务二/Ubuntu平台/01_环境准备与驱动安装.md) —— 安装 ROS 2 驱动并确认设备识别
3. [Ubuntu / 02 启动与查看数据流](任务二/Ubuntu平台/02_启动与查看数据流.md) —— 启动相机节点，在 RViz2 中查看图像与点云
4. [通用 / 02 话题与坐标系](任务二/通用/02_话题与坐标系.md) —— 话题清单、编码格式、坐标系与内参
5. [通用 / 03 机器人集成要点](任务二/通用/03_机器人集成要点.md) —— 机体坐标系挂载、外参与资源规划

> 路径占位符 `<安装目录>`（Windows）/ `<SDK 安装目录>`（Ubuntu）见各篇文首「示例环境」。
>
> 任务二为 Linux 平台的 ROS 2 接入；ROS 2 驱动以 deb 形式发布，仅覆盖 Humble / Jazzy / Lyrical 与 amd64 / arm64。
