# 奥比中光深度相机通用上手 WIKI

深度相机上手教程：开箱 → 安装 → 跑通示例 → 自写取流。不针对特定机型，示例以 **Astra 2** 为准（**Orbbec SDK v2.10.6**）。

## 文档结构

```text
通用\               平台无关，共性问题只讲一遍
├── 01 产品准备
└── 03 自写取流
Windows平台\         一体安装包 + 元数据注册
├── 01 下载安装与准备
└── 02 SDK 示例上手
Ubuntu平台\          deb 一体包 + udev 规则
├── 01 下载安装与准备
└── 02 SDK 示例上手
```

## 阅读顺序

1. [通用 / 01 产品准备](通用/01_产品准备.md) —— 开箱核对、连接与识别；确认该用 SDK v1 还是 v2（由相机型号与固件决定，与主机无关）
2. [Windows / 01](Windows平台/01_下载安装与准备.md) 或 [Ubuntu / 01](Ubuntu平台/01_下载安装与准备.md) —— 安装并完成设备权限配置；之后即可用 OrbbecViewer 查看图像
3. [Windows / 02](Windows平台/02_SDK示例上手.md) 或 [Ubuntu / 02](Ubuntu平台/02_SDK示例上手.md) —— 编译并运行 SDK 示例，跑通视频流
4. [通用 / 03 自写取流](通用/03_SDK自写取流.md) —— 写自己的取流程序（同一份代码，两平台编译命令都在文内）

> 路径占位符 `<安装目录>`（Windows）/ `<SDK 安装目录>`（Ubuntu）见各篇文首「示例环境」。
